## 500Mbps 端口配 500G 流量，到底是什么用法

这是本文最该讲清楚的一点，也是很多人买完才发现理解错的地方。

500Mbps 不等于你每个月能用 500Mbps 跑满。端口速率是上限，流量额度是总量。按 500Mbps 满速算，每秒约 62.5MB，500G 流量在满速下大约 2.2 小时就打光了。所以“500Mbps + 500G”这个组合的真实含义是：允许你短时间高速突发，不允许持续大流量。

它适合的场景很具体：远程桌面、SSH 加速、直播推流中转、临时拉个大文件、跑 CI 拉镜像。不适合的场景同样具体：做视频站、做下载站、做图床、拿它当对象存储回源。

对照另一种模型会更清楚。市面上有一类美国套餐给的是 5Mbps 或 20Mbps 小端口配不限流量，比如华纳云美国 1核1G/50G/5Mbps 专用/不限流量 ¥56/月（年付 ¥480，月均 ¥40），天下数据原生 IP 1核1G/50G/20M/不限流量 ¥75/月。5Mbps 满速跑一个月理论上是 1.6T 左右，实际上网站根本跑不满，所以“小端口 + 不限流量”对日均几千 UV 的企业站是够用且不焦虑的。

两类模型的选择规则：

- 你的流量是**持续、均匀、量不大**（企业官网、独立站、博客）→ 小端口不限流量更省心，不怕月底被掐
- 你的流量是**偶发、突发、短时高**（远程办公、推流、拉包、传素材）→ 大端口配额流量更划算，反正你平时不用

AkkoCloud 全部套餐都是后一种模型，圣何塞最低 500G、最高 6T。买之前先估一下你一个月真实跑多少 G，跑不到 500G 的，A1 mini 就够。

另外，套餐页没有把“流量用超之后怎么处理”写成显眼条款。这一条建议下单前开工单问清楚：是限速、停机，还是按量计费。问一句比月底被打个措手不及强。

## 三网 CN2 GIA 是什么水平，延迟大概多少

CN2 GIA（AS4809）是中国电信的精品国际出口，负载低、晚高峰稳，代价是贵，而且只有电信去程走这条线。第三方测评对 AkkoCloud 圣何塞的测法是：电信和移动去程走 CN2 GIA，联通去程走 HE 线路，三网回程统一走 CN2 GIA。回程统一这点比“只有去程优化”的商家实在，因为回程决定你下载、拉数据、SSH 操作的体感。

延迟方面，各家测出来的数不一样，得看口径：

- 第三方测评给 AkkoCloud 圣何塞的 Ping 大致 150–170ms
- 同一批资料里，走 CN2 优化的美国西海岸节点，中国大陆访问普遍在 130–180ms
- 阿里云开发者社区那篇选型指南给的是更宽的口径：美国节点亚太访问常规 150–250ms，晚高峰容易拥堵丢包

三个数字不冲突，测点、时段、是否走 CN2 优化都不同。你自己测最准，官网给了圣何塞的测试 IP 45.9.10.146，下单前 ping 一下、traceroute 看一下回程走哪条线，比看任何测评都直接。

面向欧美本地用户的话，线路权重就下降了，机房位置和带宽更重要。西海岸机房对美西和环太平洋地区是最近的登陆点，对欧洲就一般，那种情况该看东海岸节点。
